Native macOS App • Compatible with macOS 12 Monterey through macOS 15 Sequoia

Browse all your external drives,
without plugging in a single cable.

HyperCatalog indexes your external HDDs, SSDs, and backup archives so you can explore folder hierarchies in native macOS Column View and find any file in milliseconds.

User Guide & Support Privacy Policy

Engineered for Creators & Archivists

Lightning-fast indexing, zero bloat, and pure native macOS ergonomics.

Native Column View

Navigate folder structures smoothly using macOS Finder's familiar multi-column view. Inspect file sizes, types, and modification dates with zero lag.

⌘K Global Spotlight Search

Press ⌘K to open the instant search palette. Search through millions of files across dozens of offline drives simultaneously in milliseconds.

Portable .hcat Catalogs

Export your disk libraries into ultra-compact, standalone .hcat files. Share them via AirDrop or email so colleagues can search your archive offline.

Visual Storage Analyzer

Gain immediate visual insight into what is consuming your storage with dynamic category breakdowns (Video, Audio, RAW Photos, Documents, Archives).

Universal CSV Import

Migrate seamlessly from legacy catalog utilities (Virtual Volumes View, DiskCatalogMaker, or custom spreadsheets) with auto-encoding detection.

100% Offline & Private

Your filenames and files stay strictly on your Mac. No cloud connection, no third-party telemetry, no analytics, and zero tracking.

Technical Specifications

Platform: macOS 12.0 Monterey or later (Apple Silicon & Intel)
Supported File Systems: APFS, HFS+, ExFAT, FAT32, NTFS (read-only)
Catalog File Format: Standalone Portable JSON (.hcat), CSV Export
Security Architecture: Apple App Sandbox & Hardened Runtime compliant
